# Vectora Academic — compact brand guidelines

## Mark

The symbol is a geometric V, vector arrow and restrained orbit. Never add seals, crests, IB marks or accreditation language.

## Clear space and minimum size

- Clear space: at least the diameter of the cyan orbit point on every side.
- Full logo minimum digital width: 220 px.
- Mark minimum digital size: 32 × 32 px.
- Print minimum width: 42 mm for the full logo; 9 mm for the mark.

## Colour

| Name | RGB / HEX | Approximate CMYK starting value |
|---|---|---|
| Deep Navy | `#10233F` | C 75 / M 45 / Y 0 / K 75 |
| Warm Ivory | `#F7F4EC` | C 0 / M 1 / Y 5 / K 3 |
| Electric Cyan | `#34B7D8` | C 76 / M 16 / Y 0 / K 15 |
| Graphite | `#26313D` | C 38 / M 20 / Y 0 / K 76 |

CMYK values must be proofed against the printer’s ICC profile before final production.

## Usage

- Use the light logo on ivory and the dark logo on navy.
- Use monochrome for single-colour production.
- Do not stretch, recolour, rotate or place the mark on busy imagery.
